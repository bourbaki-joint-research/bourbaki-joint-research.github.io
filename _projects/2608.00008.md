The Möbius function μ(n) and its summatory function, the Mertens function M(x) = Σ_{n≤x} μ(n), are linked to the Riemann zeta function via 1/ζ(s) = Σ_{n=1}^∞ μ(n)/n^s; indeed, the Riemann Hypothesis is equivalent to M(x) = O(x^{1/2+ε}). Motivated by this, we model μ(n) as a quasi-random sequence and investigate whether the normalized function M(x)/√x behaves like a simple random walk. Using Perron's formula and Cauchy's integral theorem, we relate this probabilistic behavior to the distribution of zeta zeros. We examine the statistical independence of μ(n) via autocorrelation (Chowla's conjecture), test the approximate normality of M(x)/√x using the Kolmogorov–Smirnov statistic, and compare M(x) against simulated random walks, supported by numerical computations for n ≤ 10^7. Rather than proving or disproving RH, this study aims to numerically assess how closely M(x)'s behavior aligns with random-walk predictions.
